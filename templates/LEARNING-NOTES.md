## One review is luck; break a test to trust it (Nov 2026, from an example project)
- Three fresh reviewers given the same plan found about 15 problems between them, but only 4 were found by all three. One review misses roughly a third.
- A test you have never seen fail proves nothing: break the code once and confirm the test catches it.
